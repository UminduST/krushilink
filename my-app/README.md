# KrushiLink application

This directory contains the Next.js application for [KrushiLink](../README.md), a Sri Lankan farm-to-market marketplace.

## Development

```powershell
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). See the repository [README](../README.md) for Supabase setup, environment variables, features, and Vercel deployment instructions.

## Validation

```powershell
npm run lint
npm run build
npm run start
```

The production build currently passes TypeScript checking, route generation, and optimization.
